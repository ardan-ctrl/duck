# Архитектура пайплайна

## Концепция

Пайплайн строится как последовательность стадий с входом/выходом через JSON-артефакты.

1. `ingest` — чтение входного манифеста и ассетов.
2. `transcribe` — ASR и выравнивание текста по времени.
3. `storybeat` — выделение смысловых акцентов для титров.
4. `scene_plan` — планирование сцен, визуалов, маскотов, motion-элементов.
5. `compose` — сборка композиции по таймлайну.
6. `render` — рендер финального видео.
7. `qc` — автоматические проверки безопасности зон и синхронизации.

## Ключевые сущности

- `EpisodeManifest`: что пришло на вход по выпуску.
- `Transcript`: текст + таймкоды слов/фраз.
- `StoryBeats`: короткие смысловые фразы для on-screen текста.
- `ScenePlan`: сцены с таймингом, слоями, эффектами.
- `RenderPackage`: все данные для финального рендера.

## Принципы

- Конфиг важнее кода: стиль хранится в JSON/YAML.
- Детерминированность: одинаковый вход -> одинаковый выход.
- Серийность: шаблоны переиспользуются между выпусками.
- Наблюдаемость: каждая стадия оставляет артефакт в `output/<episode>/artifacts`.
