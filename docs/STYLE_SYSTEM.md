# Система стиля

## Где настраивается

- `templates/styles/default_style.json` — базовые правила.
- `templates/scenes/*.json` — шаблоны сцен.
- `templates/motions/*.json` — параметры анимаций.

## Рекомендации по контенту титров

- Не делать дословные субтитры как основной слой.
- Показывать ключевую мысль в 2-6 словах.
- Частота: 1 акцент каждые 2-4 секунды.
- Для длинных блоков: headline + короткая "рукописная" реплика поверх.

## Правила безопасной зоны

- Вертикальный формат 1080x1920.
- Отступ сверху и снизу под интерфейс платформы.
- Текст и CTA не ставить вплотную к краям.

## Маскоты и элементы

- Для каждого маскота хранить:
  - PNG/WebP со слоем прозрачности,
  - якорную точку,
  - дефолтный масштаб,
  - набор анимаций вход/выход.
